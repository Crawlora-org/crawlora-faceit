# Crawlora FACEIT API client for Ruby (`crawlora-faceit`)

This Ruby gem calls Crawlora's hosted FACEIT API at `https://api.crawlora.net/api/v1`. It exposes 35 endpoints covering leaderboards, players, teams, matches, tournaments, clips, hubs, and public game modes; it does not call or scrape FACEIT directly. Requests require your Crawlora API key and use your account's service plan.

## Install

```ruby
gem "crawlora-faceit"
```

Create an account at [crawlora.net](https://crawlora.net/signup?utm_source=rubygems&utm_medium=referral&utm_campaign=platform-clients&utm_content=faceit-ruby-signup), open the [Crawlora console](https://crawlora.net/app?utm_source=rubygems&utm_medium=referral&utm_campaign=platform-clients&utm_content=faceit-ruby-console) to get an API key, and set `CRAWLORA_API_KEY` before running the client:

```ruby
require "json"
require "crawlora/faceit"

client = Crawlora::Faceit::Client.new
result = client.request("faceit-championship-search", JSON.parse("{}"))
puts result
client.close
```

Use an operation-specific method for normal calls. `request(operation_id, params = {}, response_type: :auto)` is available for every operation. `response_type: :text` returns raw response text. This gem includes 35 API operations.

```ruby
client = Crawlora::Faceit::Client.new(api_key: ENV.fetch("CRAWLORA_API_KEY"), timeout: 30)
# client.<operation_method>(<endpoint parameters>)
client.close
```

Client options include `api_key`, `base_url`, and `timeout`. Ruby stdlib provides the HTTP and JSON support.
